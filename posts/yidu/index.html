我做了一款小游戏，叫《已读》

2026年11月27日
  • 独立游戏
  • 互动叙事

我做了一款小游戏，叫《已读》。现在的版本是 v1.1.0。

它是手绘互动绘本式的叙事游戏，单机离线。决定不是选一句台词，而是去动画面里的东西：移开手机、翻过录音机，拿起信纸、日历或杯子。人和人靠得近还是远，对白也会不一样。

故事发生在书店、河岸，还有两座城市之间。一共 6 章 18 幕，四种结局，其中有一个隐藏结局，叫「声音信」。

完全免费。不用注册账号，没有内购和广告，也不会上传数据，存档都在本地。可以在网页上直接玩，也可以下载 Windows 版。语言是简体中文，适龄 8 岁以上。

想先试试看的话，从这里进：在线试玩。也可以打开 Web 版，或在 GitHub 的 v1.1.0 发布页 下载 Windows ZIP 和网页包。TapTap 上也有商店页：《已读》。

画面是手绘绘本风格。有一部分素材用了 AI 辅助，来源写在仓库的 CREDITS.md 里。字号可以调到 100%、125% 或 150%，也有减少动态、对白回看和结局收集册。
